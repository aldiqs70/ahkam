# أحكام: علاقات الحروف

صفحة تعليمية تشرح علاقات الحروف (المِثلان، المتجانسان، المتقاربان، المتباعدان) وموانع العلاقة وموانع الإدغام، مع الأحكام والاستثناءات وتدريب تفاعلي.

- **إعداد:** رجاء يوسف
- **المرجع:** منهاج الدارسين لترتيل الكتاب المبين، المستوى الثالث، الباب الأول (ص ١٦٩–١٨٨)، ومصطلحات ضبط المصحف (ص ٣٥٥–٣٥٨). رواية حفص عن عاصم من طريق الشاطبية.

## التشغيل

الصفحة ملف واحد `index.html`. افتحه في أي متصفح، أو فعّل GitHub Pages على الفرع `main`.
